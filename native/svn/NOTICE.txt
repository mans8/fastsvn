FastSVN 内嵌 svn 引擎的第三方组件说明
=====================================

本目录下的 `bin/svn` 由 FastSVN 使用 Apache 官方源码自行编译（见
`scripts/build-svn.sh`），第三方库全部静态链接，只依赖 macOS 系统库。

组件与版本
----------
- Apache Subversion 1.14.5        Apache License 2.0
  https://subversion.apache.org/
- Apache Serf 1.3.10              Apache License 2.0
  https://serf.apache.org/
- Apache Portable Runtime 1.7.6   Apache License 2.0
- Apache APR-util 1.6.5           Apache License 2.0
- OpenSSL 3.0.16                  Apache License 2.0
  https://www.openssl.org/
- utf8proc 2.8.0                  MIT License
  https://juliastrings.github.io/utf8proc/
- SQLite 3.8.11.1（amalgamation） Public Domain
  https://www.sqlite.org/

系统提供的库（不随本应用分发）
------------------------------
libSystem / libz / libexpat / libiconv / libsasl2 / Security / CoreFoundation /
CoreServices —— 均属 macOS 系统组件。

编译参数
--------
    ./configure --prefix=... \
      --with-apr=... --with-apr-util=... --with-serf=... \
      --with-utf8proc=... --with-zlib=$SDK/usr --with-lz4=internal \
      --without-apxs --without-berkeley-db \
      --disable-nls --disable-shared --enable-static
