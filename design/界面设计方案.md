## 一、设计目标与约束

| 约束 | 对设计的具体要求 |
|------|------------------|
| 用户在 macOS 上 | 遵循 HIG：系统字体、窗口圆角与阴影、桌面级密度（36px 行高，非 44px 触控） |
| 轻度用户为主（美术/测试/实施/文档） | 术语全部改写；主操作只有两个且常驻可见 |
| 办公场景，不是编码场景 | 默认不暴露 mergeinfo 等概念 |
| 商业产品 | 观感达到"值得付费"的程度 |
| **JetBrains 匹配** | 四主题对齐 IntelliJ 标准主题集；VCS 状态色语义对齐（added 绿 / modified 蓝 / deleted 红 / unversioned 棕） |

## 二、设计方向

### 2.1 色彩策略：清新明亮的冷调

- **中性色全部冷调**：面板冷白（#FFFFFF / #F5F6F8），不掺黄。暖灰会让工具显旧、显闷；冷白 + 蓝灰边框是"新工具"的气质。
- **一个明确的主色**：JetBrains 式交互蓝 #2C6FD1（浅）/ #7DB1F1（深）。饱和度足以做主按钮，但不像纯 #0066FF 那样刺眼。
- **状态色语义对齐 JetBrains**（IDEA 用户的肌肉记忆）：**modified = 蓝**、added = 绿、deleted = 红、unversioned = 棕。v1.0 曾用琥珀表示 modified，v1.1 改回蓝。

### 2.2 三个反常规决策（v1.0 保留）

| 决策 | 常规做法 | 本方案 | 理由 |
|------|----------|--------|------|
| 术语 | 保留 SVN 术语配文档 | **界面一律改写**：工作副本→本地文件夹、提交→上传我的改动、更新→同步最新 | 目标用户不看文档 |
| 密度 | 48px 行高（移动端习惯） | **36px 行高 / 13px 正文** | 桌面鼠标精度高，一屏多 3 成信息 |
| 状态表达 | 只用颜色 | **字母 + 颜色 + 数字三重编码** | 色盲可读，颜色不承担唯一信息 |

### 2.3 记忆点（差异化细节）

1. **变更地图**——diff 最右 12px 竖条，绿/红短刻度标出改动位置
2. **增删平衡条**——提交面板顶部 5px 细条，按行数比例分配，一眼看出"加功能还是删代码"
3. **说人话的错误**——"上次操作被中断，文件夹被锁住了" + 一键修复按钮

## 三、主题体系（JetBrains 匹配）

四主题对齐 IntelliJ 平台标准主题集，命名与结构一致：

| 主题 | 对应 JetBrains 主题 | 定位 | 适合人群 |
|------|---------------------|------|----------|
| **明亮**（默认） | IntelliJ Light | 冷白面板 + 清爽蓝 | 大多数用户、明亮环境 |
| **强对比 · 亮** | High Contrast Light | 纯白底 + 加深文字与描边 | 视力较弱、强光环境 |
| **深色** | Darcula | #2B2B2B 面板 + 亮蓝强调 | IDEA 深色用户（最大重叠人群） |
| **强对比 · 暗** | High Contrast Dark | 近黑底 + 高亮文字 | 低光环境、视觉无障碍需求 |

实现要点：全部颜色走 CSS 变量，`data-theme` 属性切换，四主题共享同一布局与组件，只换 token。切换器在原型右下角。

### 4.4 主题四：强对比 · 暗

`--ink #FFFFFF`（17.26）、`--accent #82B4FF`（8.15）、其余状态色全部 ≥7.1:1。表面：窗口 `#191B1E` / 侧栏 `#101113` / 浮层 `#1E2124`。

> 以上对比度均为按 WCAG 2.1 相对亮度公式实测计算（非估算）。第一版配色有 11 项不达标，已逐项迭代至全部通过，同时优先选"刚好达标"的最亮值，保住清新明亮的观感。

### 4.5 字阶与字体

不变（同 v1.0）：系统字体 SF Pro + PingFang SC；代码 SF Mono / JetBrains Mono 回退；正文 13 / 次要 12 / 辅助 11；数字一律 `tabular-nums`。

### 4.6 间距、圆角与阴影

不变（同 v1.0）：4px 基数；控件圆角 6 / 弹层 10 / 窗口 12；阴影主色调改为蓝黑（rgba(20,34,66)），配合冷调。

## 五、布局与栅格

不变（同 v1.0）：侧栏 238px + 列表 320–404px 弹性 + diff 自适应；工具栏 58 / 状态栏 30；窗口基准 1280×820；窄于 900px 退化为单栏。

品牌：侧栏交通灯右侧常驻 `FastSVN` 字标（Fast 灰、SVN 主色蓝，12px），不占独立 logo 行——JetBrains 产品的做法。

## 六、组件规格

不变（同 v1.0 的组件表），仅记录色值变化：

- 主按钮：明亮主题蓝底白字（#2C6FD1）；深色主题亮蓝底深字（#7DB1F1 + #0F1626）——JetBrains New UI 深色主按钮的"亮底深字"样式
- 状态芯片：底色 = 状态色 13% 透明，字母 = 状态色，M 为蓝、A 为绿、D 为红、C 为橙、U 为棕
- diff 行：新增底 `rgba(add,10%)`、删除底 `rgba(del,10%)`，行号槽加深至 18%
- 选中态：主色 10% 底 + 左缘 2px 主色条

## 七、三个关键界面

### 7.1 主界面（截图 FastSVN-01~04）

打开就知道"我该做什么"：两个主操作（同步最新 / 上传我的改动+数量徽标）常驻工具栏；列表一行一个文件（状态芯片 → 文件名 → 路径 → +18 −4 → 时间）；点击即出 diff，不跳页；冲突文件点击直接进冲突面板；二进制文件明说"不做逐行对比"。

### 7.2 提交审查面板（截图 FastSVN-05）

顺序刻意安排：总量四宫格 → 增删平衡条 → 风险警示（动态：勾掉风险文件即消失）→ 文件清单 → 说明输入。说明为空时不静默失败，输入框变红并给出引导文案。3 个常用说明模板降低填写成本。

### 7.3 冲突解决（截图 FastSVN-06）

标题"这个文件你和同事都改了"；三个选项带后果说明（全部用我的 / 全部用同事的 / 逐行挑选）；两版代码直接对照；底部提示"还有 2 个文件也有冲突"。

## 八、无障碍

| 项 | 落实 |
|----|------|
| 对比度 | 四主题 × 9 文本色 × 3 表面全部 ≥4.5:1（实测） |
| 颜色冗余 | 状态 = 字母 + 颜色 + 数字；冲突另有图标 |
| 键盘 | Tab 全可达；行 Enter/Space 选中；Esc 关闭；⌘K 上传、⌘R 同步 |
| 主题 | 强对比两主题即 JetBrains 的无障碍主题定位 |
| 动效 | 尊重 `prefers-reduced-motion` |

## 九、给开发的还原说明（JetBrains 匹配版）

1. **主题实现**：CSS 变量 + `data-theme`，参考 `prototype.html` 的 `:root` 与 `[data-theme=...]` 四块 token；AppKit 侧可用 NSAppearance + 自定义 token 表。
2. **状态色语义别改**：modified=蓝 是 JetBrains 用户习惯，不要改回琥珀或紫色。
3. **深色主题的主按钮用"亮蓝底 + 深字"**（JetBrains New UI 做法），不是浅蓝底白字。
4. 别改字号（13/11 桌面密度）；别加卡片；别用 Web 字体；数字用 tabular-nums。
5. 危险色（红/橙）只用在真危险处。diff 语法高亮保持低饱和。
6. 品牌字标只做 `FastSVN` 文字（Fast 常规灰 + SVN 主色），后续做图标时保持同一对比关系。
